# 华为杯优秀论文提炼：写作与排版模式

本参考服务于竞赛论文的可读性与可核查性。它归纳常见有效模式，不把往届排版当作当年强制要求。

## 叙事结构

- 摘要用有限篇幅交代问题、总路线、各子题的方法和已冻结的关键结果，最后给出验证、适用范围或局限；摘要在结果冻结后定稿。
- 正文常见有效顺序是：问题重述/分析，假设与符号，数据与模型，求解，结果讨论，评价与限制，结论，附录。子题可按同一骨架展开，但不应机械重复。
- 一段只完成一个推进动作：提出对象或结论，给出公式/图表/数值证据，解释其作用或边界。删除没有信息增量的连接语。
- 结果段优先使用“结果 -> 比较 -> 解释 -> 不确定性 -> 适用范围”的顺序；结论逐题回应题目，不把未验证的外推写成结论。

## 数学与视觉表达

- 公式要服务于模型定义、目标、约束或求解，符号首次出现即定义，单位和索引全篇一致。
- 图表承担一个可陈述的结论：流程/机制图解释模型结构，表格保留精确值，曲线或分布图说明趋势、差异或稳健性。
- 图、表、公式应编号并在正文先引用后出现；题注说明对象、条件和读者应看到的要点，不能只复述图名。
- 常见有效页面为单栏、层级编号清晰、图表位置稳定、留白受控。具体字体、页边距、封面和页数只遵循当年模板。

## 禁止的替代品

- 不用修辞替代比较、误差或约束验证。
- 不用“创新”“显著”“最优”等字眼替代限定范围内的证据。
- 不把调参过程、失败尝试或调试日志写成主线；只有在解释实际取舍时才保留。
- 不将漂亮但未通过渲染检查、不可溯源或无法支撑主张的图放进正文。
