# 华为杯优秀论文提炼：建模与证据原则

本参考来自 2004--2025 年研究生数学建模竞赛优秀论文的横向阅读与抽样版面核查。它是用于校准工作流的经验性参考，不是评分规则，也不替代当年赛题要求。

## 发现

- 高质量论文通常不是单一算法的展示，而是围绕问题机理串联若干角色明确的模块：抽象、估计/拟合、决策/优化，以及验证或仿真。
- 可复核的结果链比方法名称重要。常见的可信结构包括：机制模型配合参数拟合后优化；解析模型配合独立仿真；预测配合决策；图像/信号处理配合特征提取和重建；图模型配合资源约束调度。
- 复杂模块只有在它解决了一个前序模型无法解决的明确缺口时才有价值。算法堆叠、只报单一结果、只与不可比方法比较，都不能构成创新。
- 可读论文会把每道子题的输出、比较或误差、适用边界放在读者能找到的位置。历史样本中显式稳健性章节并不稳定，因此现代提交应主动补足该证据。

## 对工作流的要求

1. 在算法筛选前，先写清 `现实对象 -> 数学对象 -> 变量/状态 -> 约束 -> 输出 -> 验证`。
2. 为每道子题定义模型层次、层间输入输出、主张、证据和失败边界；没有角色的模块不进入主路线。
3. 主方法必须有可完成真实任务的 baseline；需要时增加消融、理论检查、独立仿真或压力场景，而不是只扩大算法清单。
4. 最终论文中的每项核心主张都须能追溯到冻结数值、图表或可复现的检查；无法验证的内容应转化为限制或删去。
5. 审查“冲一等奖”准备度时评价完整性、数学实质、证据独立性、可用性与表达，不承诺竞赛名次。

## 适用边界

- 赛题规则、页数、封面、模板和 AI 使用披露必须以当年官方文件为准。
- 历史论文中的篇幅和版式差异较大，不能由历史样本推断当前硬性格式。
- 竞赛论文必须独立完成；本参考不允许复用、改写或伪造往届论文的内容、数据或结论。
